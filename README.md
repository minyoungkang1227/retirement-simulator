## 왜 만들었나

국내 은퇴 계산기는 대부분 수익률과 수명을 고정한 단순 계산이고, 세금·건강보험료가 빠져 있어 결과가 낙관적입니다. 해외 도구(Boldin, ProjectionLab)는 확률 시뮬레이션을 쓰지만 미국 제도 기준입니다. 이 프로젝트는 **한국 제도 + 확률 모델 + 계리 모델**을 하나로 묶어 그 빈자리를 채웁니다.

## 이렇게 동작합니다

```
① 단계별 입력 (20세부터): 은퇴 시점 → 자산·소득·저축 → 기본생활비 → 여행 예산 → 연금 → 남길 자산 → 투자 성향 → 최종 확인
② 1만 개 시나리오: 금리·물가·주가(연결된 확률과정) × 부부 각자의 수명·간병(다중상태 모델)
③ 현금흐름: 은퇴 전 저축 → 은퇴 후 기본생활비 우선, 여유가 있을 때만 여행 예산 지출
④ 세금·건보료·보유세·상속세 반영
⑤ 결과: Income Gap, 목표별 달성 확률, 필요 금융자산·필요 저축액, "직접 바꿔보기"(은퇴 시기·저축·생활비·국민연금·투자 성향 슬라이더, 변화 곡선, 주택연금·집 줄이기 비교), "상품 추가해 보기"(예금·연금·보험)
```

## 차별점

1. **목표 기반 구조** — 기본생활(지켜야 할 목표), 여행·취미(조정 가능한 목표), 남길 자산을 나누고, 나쁜 시나리오에서는 선택 지출부터 줄이는 가드레일 규칙을 적용 (보호선 = 생존확률 가중 기대 부족분 현가)
2. **한국 제도** — 국민연금 조기·연기수령, 사적연금 1,500만원 분리과세, 금융소득종합과세, 건강보험료(지역/직장, 피부양자), 재산세·종부세, 상속·증여세
3. **계리 모델** — 통계청 2024 완전생명표 + 코호트 사망률 개선(연령별 연간 0.3~2.5%, 통계청 추이로 검증), 부부 공동생존, 간병 다중상태 마르코프(건강 → 경증 → 중증 → 사망, 장기요양 통계로 보정), 연금 상품(종신·부부형·보증기간·체증·거치형) 수지상등 가격, 생명표 사망률 보존 보정
4. **확률 경제 모델** — ECOS 실데이터로 추정한 실질금리·물가 OU 과정과 피셔 연결, 2요인 채권 가격 해석해, 1년 금리 적분의 정확한 결합분포, 폭락 점프, 파라미터 불확실성, 운용보수
5. **통계적으로 정직한 비교** — 공통 난수 위에서 경로별 차이로 신뢰구간을 계산해 "차이 있음 / 없음"을 판정

## 결과 예시 (모델 v50 · 경로 1만 개 · `scripts/readme_numbers.py` 로 재현)

**52·50세 부부, 60세 은퇴, 금융자산 5억, 월 저축 150만 원** (기본생활비 월 300만 원 + 여행 연 1,200만 원, 연금 월 160만 원, 1억 남기기)

- 목표 달성: 기본생활 유지 **53%**, 여행·취미 충족 **70%**, 1억 남기기 **43%**

| 무엇을 바꾸면 | 기본생활 유지 확률 변화 (95% 신뢰구간) |
|---|---|
| 은퇴 2년 늦추기 | **+10.9%p** (±0.6) |
| 생활비 10% 줄이기 | +8.4%p (±0.6) |
| 투자 성향 성장형 (주식 70%) | +5.0%p (±0.5) |
| 월 저축 50만 원 늘리기 | +4.4%p (±0.4) |
| 투자 성향 보수형 (주식 30%) | −13.0%p (±0.7) |

| 위기 상황 | 기본생활 유지 확률 변화 |
|---|---|
| 은퇴 첫해 주가 −40% | −15.9%p |
| 은퇴 10년 뒤 주가 −40% | −10.0%p |
| 3년 연속 물가 6% | −5.0%p |
| 예상보다 오래 삶 (사망률 −20%) | −3.4%p |
| 간병 위험 2배 | **−4.1%p** |

- 이 가구에서는 **은퇴 시점이 가장 강력한 수단**이고, 같은 폭락도 **은퇴 직후**에 올수록 치명적입니다(수익률 순서 위험).
- **가정 범위는 42%~64%입니다.** 주식 위험프리미엄·수명·간병 발생률을 각각 추정 폭만큼 움직인 결과의 최소·최대입니다(v47). 폭은 사실상 **위험프리미엄**이 만듭니다 — 위험프리미엄만 ±1 표준오차(5.2% ± 1.4%p) 움직이면 42%~64%, 수명은 52%~54%, 간병 발생률(±20%)은 52%~54%입니다. 몬테카를로 오차 ±0.7%p는 그 1/15이고, 이 범위는 경로를 늘려도 줄지 않습니다. 그래서 절대값보다 **선택지 간 차이**를 보는 것이 중요합니다.

**20~40대 (30·29세 맞벌이, 연 소득 9,000만 원, 저축률 15%, 퇴직연금 적립, 국민연금 자동 추정)**

- 기본생활 유지 **79%**, 여행·취미 충족 **93%**, 1억 남기기 **74%**
- 무엇을 바꾸면: 월 50만 원 더 저축 +7.8%p · 은퇴 2년 늦추기 +5.9%p · 생활비 10% 줄이기 +5.0%p
- **퇴직연금이 없다면 −25.2%p** — 이 또래에서는 퇴직연금 적립 여부가 다른 어떤 선택보다 큽니다.

**집은 있고 현금은 적은 가구 (65·63세 부부, 금융자산 3억, 집 시세 7억·공시 5억, 기본생활비 월 250만 원 + 여행 연 1,200만 원, 3억 남기기)**

| 주택 활용 | 기본생활 유지 | 여행·취미 충족 | 3억 남길 확률 | 비고 |
|---|---|---|---|---|
| 그대로 | 14% | 35% | 94% | — |
| 주택연금 지금 가입 (63세) | 81% (+67.6%p) | 98% | 70% | 월 165만 원 |
| 주택연금 70세 가입 | 86% (+72.6%p) | 92% | 74% | 월 225만 원 (오늘 가치) |
| 70세에 절반 가격 집으로 이사 | 78% (+63.9%p) | 92% | 87% | 현금 3.5억 확보 |

- 집이 자산의 대부분인 가구는 **집을 활용하느냐가 가장 큰 선택**입니다. 주택연금은 노후 안정성을, 집 줄이기는 상속까지 함께 지키는 쪽으로 맞교환이 갈립니다.
- v45에서 건보료 재산분을 반영하면서 이 가구의 수치가 v44보다 2~5%p 낮아졌고, v47의 지출 경직성 반영으로 다시 5%p 낮아졌습니다(집이 있는 가구일수록 은퇴 후 고정비가 크고, 줄이기 어려운 지출의 영향도 그만큼 큽니다).

> **v50 (2026-10-26):** **세 가지 빈자리를 메웠습니다.** ① **나이에 따른 지출 변화** — 지금까지는 기본생활비와 여행 예산이 평생 같았는데, 실제로는 나이가 들수록 여행·여가는 줄고 의료비는 늘어납니다. 자본시장연구원(2025, 재정패널 2008~2021)에서 60~64세 대비 균등화 실질소비가 75세 이상 43% 수준이고 Blanchett(2014)도 60~90세 연 −1%였지만, 단면 자료에는 '돈이 없어 못 쓰는' 효과가 섞여 있어 보수적으로 **여행·취미만 75세부터 줄어 85세에 절반**을 기본으로 했습니다(기본생활비까지 줄이는 선택, 평생 같게 두는 선택도 있음). 위 예시 가구는 49% → **53%**. ② **은퇴 후 근로**(재취업·파트타임) — 근로소득공제·세액공제, 직장 건보료 본인부담, 기초연금 근로소득 공제까지. 월 200만 원을 65세까지 벌면 +6.6%p, 70세까지면 +11.3%p. 국민연금은 2026년 6월 개정으로 월 약 519만 원 이하 근로면 깎이지 않아 감액하지 않았습니다. ③ **전월세 보증금** — 상속재산, 기초연금 재산, 건보 재산(30%)에 넣습니다. 보증금 5억이면 −10%p인데, 그동안 기초연금을 받는 것으로 잘못 계산하던 것이 바로잡힌 결과입니다.

> **v49 (2026-10-26):** **퇴직금·퇴직연금과 퇴직소득세를 넣었습니다.** 지금까지는 매년 연봉의 1/12이 쌓이는 DC형 하나뿐이었는데, 이제 **DC형과 DB형·퇴직금 제도**(마지막 월급 × 근속연수) 중 고르고 근속연수를 넣습니다(1단계에도 체크 하나와 근속연수). 은퇴 때 IRP로 받아 연금으로 나눠 쓴다고 보고 **퇴직소득세**(근속연수공제 → 환산급여 → 환산급여공제 → 기본세율 × 근속연수/12, 지방세 10%)를 계산하며, 연금수령 1~10년차는 그 70%, 11년차부터 60%만 냅니다. 손검산(1억·근속 10년 = 426.25만 원)을 테스트로 고정했습니다. 52세·연봉 6,000만·근속 20년이면 퇴직금 1.5억, 기본생활 유지 확률 79.0% → **87.7%**. 처음엔 IRP부터 꺼내게 했다가 과세계좌가 불어나 금융소득세·건보료가 늘면서 오히려 −2.4%p가 나와, 인출 순서는 v48과 같게(연금계좌 합쳐 1인당 연 1,500만 원) 두었습니다 — 그러면 v48 대비 차이는 세율뿐(+0.4%p)입니다.

> **v48 (2026-10-26):** **입력을 세 단계로 나눴습니다** — 첫 화면에서 **1단계 빠른 진단**(혼자 3분), **2단계 내 재산 반영**, **3단계 전문가 상담** 중 고릅니다. 묻는 순서는 측정으로 정했습니다: 각 입력을 '기본값으로 때울 때 생길 오차'만큼 움직여 보니 은퇴 나이(33.5%p)·기본생활비(29.7%p)·여행 예산(24.0%p)·금융자산(18.7%p)·투자 성향(18.3%p)·집·대출이 압도적이고, 사별 후 생활비(6.2%p)·부모 간병(2.9%p)·해외주식(1.2%p)은 작습니다. 영향이 크고 누구나 답할 수 있는 것은 1단계, 세금 계산에 필요한 세부는 2단계, 일반인이 답하기 어려운 판단값은 3단계입니다. 묻지 않은 값은 기본값으로 채우고 결과 화면에 무엇을 가정했는지 적습니다. 함께: **이미 갚고 있는 대출**을 넣을 수 있습니다(지금까지는 앞으로 받을 대출만 가능). 은퇴 후까지 남는 상환분만 노후자금에서 나가며, 2억·20년 남은 대출이면 −13.0%p입니다. 대출이 없으면 결과는 v47과 같습니다. 측정표 전체는 [CHANGELOG](CHANGELOG.md)에 있습니다.

> **v47 (2026-10-26):** **지출 경직성을 기본으로 켰습니다.** 형편이 나빠져도 생활 수준을 한 해에 30% 넘게는 못 줄인다는 것은 투자 행동이 아니라 가계 지출의 구조적 성질이라, v36에서 구현해 두고 '행동 가정' 토글에 묶어 꺼 두었던 것을 기본값(`lifestyle_floor=0.30`)으로 돌렸습니다. 8만 경로로 잰 효과는 기본 가구 **−1.3%p**, 60세 은퇴 직후 부부 **−3.0%p**. 위 예시 가구도 다시 돌렸습니다 — 52·50세 부부 52% → **49%**, 집 있고 현금 적은 가구 17% → **12%**(고정비가 이미 큰 가구일수록 영향이 큽니다). 함께: **가정 범위를 위험프리미엄 하나에서 세 요인으로** 넓혔습니다(위험프리미엄 ±1 표준오차, 사망률 수준 ±1σ, 간병 발생률 ±20%를 하나씩 움직인 6개 결과의 최소·최대). 측정해 보니 폭은 **위험프리미엄이 지배**합니다 — v46의 범위가 과소는 아니었지만, 이제 어느 가정이 폭을 만드는지 근거와 함께 말할 수 있습니다. `tax.progressive`·`tax.hi_property_points`를 `searchsorted`로 바꿔 1만 경로 1회가 **0.94초 → 0.78초**(결과는 비트 단위로 동일). `docs/MODEL.md`의 경제·사람 장을 현재 사양으로 통합해 다시 쓰고 참고문헌 20건을 붙였으며, 영문판도 맞췄습니다. 테스트 121 → 122개.

## 사용법

- **웹 앱:** 위 링크에서 한 단계씩 입력 → "이 조건으로 계산하기"
- **태블릿 앱:** 위 주소를 태블릿 브라우저로 열고 공유 → '홈 화면에 추가'. 처음 한 번 계산 엔진(약 17MB)을 받은 뒤로는 인터넷 없이 열립니다. 배포는 GitHub 저장소 Settings → Pages → Branch `main` · 폴더 `/docs` 한 번만 켜면 됩니다.
- **Colab:** 배지를 누르고 `런타임 > 모두 실행`, 2단계 입력 셀만 수정
- **로컬:**
  ```bash
  pip install -r requirements.txt
  streamlit run streamlit_app.py      # 웹 앱
  python -m pytest -q                 # 이론값 검증 포함 전체 테스트
  python scripts/build_app.py         # 엔진을 고쳤다면 태블릿 앱 묶음도 다시
  cd docs/app && python -m http.server 8000   # 태블릿 앱을 로컬에서 열어 보기 (http://localhost:8000)

  PYTHONPATH=. python scripts/check.py              # 오류 검증 + 최적화 점검 한 번에
  PYTHONPATH=. python scripts/run_example.py        # 화면 없이 엔진만 돌려 보기
  PYTHONPATH=. python scripts/make_readme_images.py # 이 문서의 그림 다시 만들기
  PYTHONPATH=. python scripts/make_sources_doc.py   # 자료 출처 문서 다시 만들기
  ```

## 한계와 주의

- 임시값은 없습니다. 쓰인 자료와 반영 시점은 **[docs/SOURCES.md](docs/SOURCES.md)** 에 한 곳으로 모아 두었습니다(`retire_sim/sources.py` 에서 자동 생성).
- 다만 **주식 위험프리미엄의 추정 오차가 큽니다**(1σ 폭 13.7%p). 절대값 하나를 믿지 말고 **선택지 간 차이**를 보세요 — 그쪽은 같은 난수를 공유해 오차가 훨씬 작습니다(±0.44%p).
- **제도 값은 현행 법령 기준의 고정값**입니다. 법이 바뀔 위험(개정·시행령 변경)은 확률모형 안에 없습니다. 갱신은 출처 목록(`retire_sim/sources.py`)이 시점과 순서를 관리하는 **반자동** 방식이고, 자동 개정 감지는 아직 없습니다.
- 건보료 재산분은 자동차 점수와 월세 환산분을 아직 반영하지 않습니다(전월세 보증금은 v50부터 반영).
- 국민연금을 소득으로 자동 추정할 때 과거 가입기간의 높은 소득대체율·크레딧·부양가족연금은 넣지 않아 **낮게 추정될 수 있습니다**(예상 월액을 직접 넣으면 영향 없음).
