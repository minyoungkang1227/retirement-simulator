# 모델 문서 — 확률 기반 은퇴 시뮬레이터

**한국어** | [English](MODEL.en.md)

> 기준일 2026-09 · 모든 금액 단위: 만원 · 시간 단위: 1년

## 1. 목적과 범위

이 모델은 은퇴 가구의 자산이 생존 기간 동안 버틸 확률을 계산하고, 두 가지 질문에 답한다.

- **① 선택지 비교**: 국민연금 개시 나이, 인출 순서, 자산 배분 등 선택에 따라 고갈확률이 어떻게 달라지는가
- **③ 보험 가치 정량화**: 보유·신규 보험이 고갈확률과 부족액을 얼마나 줄이며, 그 비용은 얼마인가

결과는 추천이 아니라 **동일 시나리오 하의 비교**로 제시한다.

## 2. 표기

| 기호 | 의미 |
|---|---|
| $W_t$ | t년 시작 시점 유동자산(명목) |
| $r_t$ | 단기금리 |
| $\pi_t$ | 물가상승률, $CPI_t=\prod_{s<t}(1+\pi_s)$ |
| $q_x$ | x세의 1년 사망확률 |
| ${}_tp_x$ | x세가 t년 후 생존할 확률 $=\prod_{s=0}^{t-1}(1-q_{x+s})$ |
| $N$ | 시뮬레이션 경로 수 (기본 10,000) |

## 3. 경제 시나리오

### 3.1 단기금리 — Vasicek

$$dr_t=\kappa_r(\theta_r-r_t)\,dt+\sigma_r\,dW^r_t$$

정확 이산화(Δt=1):

$$r_{t+1}=\theta_r+(r_t-\theta_r)e^{-\kappa_r}+\sigma_r\sqrt{\tfrac{1-e^{-2\kappa_r}}{2\kappa_r}}\,\varepsilon^r_{t+1}$$

### 3.2 물가 — Ornstein–Uhlenbeck

금리와 동일한 형태, 파라미터 $(\kappa_\pi,\theta_\pi,\sigma_\pi)$. 정확 이산화 사용.

### 3.3 주식

$$\ln(1+R^S_t)=r_t+\text{ERP}-\tfrac12\sigma_S^2+\sigma_S\,\varepsilon^S_t$$

### 3.4 채권 — 만기 D년 롤링 펀드

Vasicek 무이표채 가격 해석해:

$$P(\tau,r)=\exp\{A(\tau)-B(\tau)r\},\quad B(\tau)=\tfrac{1-e^{-\kappa_r\tau}}{\kappa_r},$$
$$A(\tau)=\Big(\theta_r-\tfrac{\sigma_r^2}{2\kappa_r^2}\Big)(B(\tau)-\tau)-\tfrac{\sigma_r^2B(\tau)^2}{4\kappa_r}$$

1년 수익률: $R^B_t=P(D-1,r_{t+1})/P(D,r_t)-1$ (위험프리미엄 0 가정).

### 3.5 상관

$(\varepsilon^r,\varepsilon^\pi,\varepsilon^S)$는 상관행렬 $C$를 갖는 표준정규. Cholesky 분해 $C=LL^\top$로 생성.

| 파라미터 | 값(임시) | 파라미터 | 값(임시) |
|---|---|---|---|
| $r_0,\theta_r,\kappa_r,\sigma_r$ | 2.5%, 3%, 0.15, 1% | ERP, $\sigma_S$ | 4%, 18% |
| $\pi_0,\theta_\pi,\kappa_\pi,\sigma_\pi$ | 2%, 2%, 0.40, 1% | D | 5년 |
| $\rho_{r\pi},\rho_{rS},\rho_{\pi S}$ | 0.5, −0.2, −0.1 | | |

## 4. 사망률

- 현재: Gompertz $\mu(x)=a e^{bx}$, 60세 기대여명 남 23.5년·여 29.5년에 보정 (**임시**)
- 교체 예정: 통계청 완전생명표 $q_x$ (CSV 로더 구현 완료)
- 부부는 독립 가정 하에 각각 생존 시뮬레이션. 최후생존 확률 ${}_tp_{\overline{xy}}={}_tp_x+{}_tp_y-{}_tp_x\,{}_tp_y$

## 5. 제도 규칙 (2026-09 기준, 설정 파일로 분리)

- 국민연금: 조기수령 연 6% 감액(최대 5년), 연기 연 7.2% 가산(최대 5년), 물가 연동
- 사적연금: 연 1,500만원 이하 3.3~5.5% 분리과세, 초과 시 전액 종합과세 또는 16.5% 분리과세 (12절)
- 건강보험 피부양자: 공적연금 포함 연소득 2,000만원 이하, 사적연금 제외 (12절)

## 6. 현금흐름 재귀식

경로별, 매년:

$$W_{t+1}=\max\big(W_t+I_t-C_t-K_t,\,0\big)\,\big(1+wR^S_t+(1-w)R^B_t\big)$$

- $I_t$: 생존자의 국민연금($\times CPI_t$) + 사적연금(명목 고정)
- $C_t$: 생활비 $\times CPI_t\times$ (1인 생존 시 0.7)
- $K_t$: 간병비. 75세 이상 생존자에게 연 $\lambda$ 확률로 발생, 비용 로그정규, 3년 지속
- 고갈: 가구 생존 중 $W_t+I_t-C_t-K_t\le0$ 최초 시점

## 7. 결과 지표

| 지표 | 정의 |
|---|---|
| 고갈확률 | $P(\text{고갈 시점}<\text{최후 사망 시점})$ |
| 고갈 나이 분포 | 고갈 경로의 고갈 시점 분위수 |
| 기대부족액 | 고갈 경로에서 부족 금액의 현가 평균 *(예정)* |
| 팬 차트 | 생존 가구 실질자산 $W_t/CPI_t$의 5·25·50·75·95 분위 |

선택지 비교는 **공통 난수(common random numbers)** 를 사용해 차이가 선택에 의한 것임을 보장한다.

## 8. 보험 모듈 (이론 확정, 구현 예정)

- 종신연금 현가: $\ddot a_x=\sum_t v^t\,{}_tp_x$, 연금액 = 일시납 / ($\ddot a_x\times$(1+부가율))
- 사망률 크레딧: 생존자 실효수익 $(1+i)/(1-q_x)-1$
- 간병보험 순보험료(수지상등): $P\,\ddot a_{x:\overline{n}|}=B\sum_t v^{t+1}{}_tp_x\,i_{x+t}$
- 생사혼합: $A_{x:\overline{n}|}=A^1_{x:\overline{n}|}+{}_nE_x$
- 가격은 경험생명표, 시뮬레이션은 국민생명표로 분리 → 보험사 마진이 드러남
- 보험금·연금은 엔진의 동일 사망·간병 사건에 연결
- 가치 지표: Δ고갈확률, Δ기대부족액, 사업비 기대현가, 100만원당 효율

## 10. 민감도 분석 (예시 가구, 기준 고갈확률 39.9%)

| 가정 (낮음 / 높음) | 고갈확률 | 폭 |
|---|---|---|

| 장기 금리 2% / 4% | 52.9% / 27.7% | 25.2%p |
| 주식 비중 20% / 60% | 53.3% / 35.3% | 18.0%p |

## 11. 한계

- 파라미터 불확실성: 미래 기대수익률은 추정 오차가 크다 → 범위·시나리오로 표시
- 확률의 해석: 고갈확률은 1만 개 시나리오의 통계이며 개인의 결과를 예측하지 않는다
- Vasicek은 음의 금리 허용(경로의 약 4.7%) → CIR 비교 예정
- 채권 위험프리미엄 0, 부부 사망 독립 가정
- 모델 밖 사건(이혼, 자녀 부양, 부동산 급락 등)과 미래 제도 변경은 반영 불가
- 절대값보다 **선택지 간 차이**가 신뢰도가 높다 (공통 가정의 오차가 상쇄)
